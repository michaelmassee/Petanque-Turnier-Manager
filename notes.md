## 🇩🇪 Deutsch
- PTM-Online-Optionen: „Verbindung testen“ zeigt das Ergebnis jetzt in einem Meldungsfenster – bei Erfolg mit dem nächsten Schritt, bei Fehlern mit der Ursache. Fehlt der API-Key oder ist „Verbindung aktiv“ nicht angehakt, gibt es einen Hinweis statt keiner Reaktion.
- PTM-Online verbinden: Das Turnierdatum erscheint im lokalen Format (z. B. 25.11.2026), die Eckdaten nennen zusätzlich die Anzahl der Anmeldungen mit Teilnehmergrenze (z. B. 12 / 32).
- PTM-Online: Meldungstexte verweisen nicht mehr auf das (inzwischen optionale) Blatt „PTMOnline Sync“; bei Zuordnungsfehlern hilft jetzt „Zuordnung vom Server wiederherstellen“.

## 🇬🇧 English
- PTM Online options: "Test connection" now shows the result in a message window – on success with the next step, on failure with the cause. If the API key is missing or "Connection enabled" is not ticked, a hint is shown instead of nothing happening.
- Connect to PTM Online: The tournament date is shown in the local format (e.g. 25/11/2026), and the key facts additionally show the number of registrations with the participant limit (e.g. 12 / 32).
- PTM Online: Messages no longer refer to the (now optional) "PTMOnline Sync" sheet; for mapping errors, "Restore mapping from server" now helps.
